# Privacy Policy / 隐私政策

**Edge Translation Guard**  
**Last updated / 更新日期:** October 3, 2026 / 2026 年 10 月 3 日

## English

Edge Translation Guard helps interactive websites continue working after Microsoft Edge's built-in page translator changes translated text nodes.

### Information processed

The extension runs on HTTP and HTTPS pages. When translation-related DOM changes are detected, it temporarily processes relevant page nodes and text values in memory to repair references used by the website's interface. Page content is not sent to the publisher or any third party, and the extension does not persist page content.

If a user pauses protection for a site, the extension stores that site's hostname in Microsoft Edge's local extension storage. This setting is not synchronized or transmitted. It remains until the user clears the extension's local data or removes the extension.

### Network and third parties

The extension does not make network requests, use analytics or tracking, load remote code, or share information with third parties. It does not provide a translation service; translation is controlled by Microsoft Edge.

### User controls and deletion

Users can enable or pause protection for the current site from the extension popup. Users can clear the locally stored setting in Edge's extension settings or remove the extension to delete its local data.

### Changes and contact

This policy will be updated if the extension's data practices change. For privacy questions, contact the maintainers through [GitHub Issues](https://github.com/SJyueluo/edge-translate-guard/issues).

## 中文

Edge 翻译保护用于修复 Microsoft Edge 内置网页翻译改变文本节点后，部分交互式网站可能发生的页面错误。

### 处理的信息

扩展会在 HTTP 和 HTTPS 网页中运行。检测到与翻译相关的 DOM 变化时，它会在内存中临时处理相关页面节点和文本值，以修复网站界面所依赖的节点引用。页面内容不会发送给维护者或第三方，扩展也不会持久保存页面内容。

用户暂停某个网站的保护时，扩展会将该网站的主机名保存在 Microsoft Edge 的本地扩展存储中。这项设置不会同步或传输；用户清除扩展本地数据或移除扩展后，该设置会被删除。

### 网络与第三方

扩展不发起网络请求、不使用分析或跟踪代码、不加载远程代码，也不向第三方共享信息。扩展本身不提供翻译服务；网页翻译由 Microsoft Edge 控制。

### 用户控制与删除

用户可以通过扩展弹窗对当前网站启用或暂停保护。用户可以在 Edge 扩展设置中清除本地设置，也可以移除扩展以删除其本地数据。

### 政策更新与联系

如果扩展的数据处理方式发生变化，本政策会随之更新。隐私问题可通过项目的 [GitHub Issues](https://github.com/SJyueluo/edge-translate-guard/issues) 联系维护者。
